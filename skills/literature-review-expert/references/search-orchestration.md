# Search Orchestration Engine

The quality of a literature review depends primarily on the quality of its
search strategy. A brilliant synthesis built on a lazy search is still a weak
literature review — it just looks confident.

Never begin searching immediately after receiving a request. Always design the
search before executing it. Searching is a scientific process, not a
retrieval task: the goal is to characterize the evidence base, not to return
the first plausible-looking set of hits.

---

## Step 1 — Understand the research question

Identify the actual scientific objective before typing anything into a search
tool. Do not search using the user's sentence verbatim — a verbatim search
tends to return whatever is easiest to find rather than what is scientifically
relevant.

Work out:

- primary research question
- biological system involved
- taxonomic scope
- ecological scale (individual, population, community, landscape)
- geographic scope
- temporal scope
- methodological scope (e.g. telemetry, camera trap, genetic, survey-based)
- intended application (background section, hypothesis generation, grant
  justification, methods comparison, etc.)

If the request is ambiguous, infer the most likely scientific objective from
context rather than stopping to ask. Only ask a clarifying question if the
ambiguity would substantially change what gets searched and reviewed — e.g.
"golden jackal diet" could mean diet composition studies or human-wildlife
conflict over livestock, and those pull from different literatures.

## Step 2 — Decompose the question

Break a complex research question into independent, separately searchable
components rather than relying on one broad search. For example, a question
about human–golden jackal conflict decomposes into: population ecology,
movement ecology, habitat selection, diet, disease ecology, human dimensions,
management, conservation, and knowledge gaps. Each component gets its own
search strategy — a single combined search under-covers most of these.

## Step 3 — Generate search concepts

For every component, work out:

- primary terminology
- alternative/synonymous terminology
- historical terminology (older papers may use outdated terms for the same
  concept)
- taxonomic synonyms and common vs. scientific names
- methodological terminology
- statistical terminology
- regional terminology
- British and American spelling variants
- singular/plural forms
- common abbreviations

Expand the concept list before generating actual queries. A search for
"jackal" alone misses papers indexed under "Canis aureus," and a search
for "movement ecology" misses papers that only use "home range" or
"space use."

## Step 4 — Select tools honestly

Use whichever evidence source actually fits, not whichever is easiest to call.
Before writing a search plan, check what's actually available in this session
rather than assuming a fixed tool list — availability can change.

**Directly queryable (when connected in this session):**
- Consensus — synthesizes findings across peer-reviewed papers directly.
- PubMed — biomedical and life-science literature, strong for disease
  ecology, genetics, and anything with a biomedical angle.
- bioRxiv — preprints; useful for very recent work not yet in a journal.
- Scholar Gateway — full-text academic search with passage-level citations.

**Reachable only through general web search/fetch, not a direct database
query:**
- Web of Science, Scopus, CrossRef, OpenAlex, Google Scholar, individual
  journal websites.
- Results found this way should be treated with the same source-quality
  skepticism as any web result — verify bibliographic details before citing,
  don't assume completeness of coverage, and say so if the user seems to
  expect a real Web of Science/Scopus query and only a web search is possible.

**General web search/fetch** — useful to supplement the above, especially for
grey literature (agency reports, theses, conference proceedings) that formal
databases under-index, but should supplement rather than replace searches
through the tools above.

Never stop searching just because one source produced results that look
sufficient — different sources capture different, only partially-overlapping
slices of the literature, and combining them is how real reviews avoid missing
whole subfields.

## Step 5 — Search until evidence saturation, not until a target count

Do not define "enough searching" by a fixed number of papers. A target like
"find 10-15 papers" is scientifically arbitrary: some topics have a single
seminal paper and nothing else worth citing, others have hundreds of relevant
studies. The right stopping criterion is evidence saturation — keep expanding
the search until additional searches stop turning up genuinely new evidence,
sources, or perspectives.

Search depth should scale with the complexity of the question:
- A narrow factual question may saturate after a handful of high-quality
  sources.
- A comprehensive review section needs iterative searching across multiple
  concepts, tools, citation networks, and time periods before it saturates.

## Step 6 — Expand via the citation network

Once important papers are identified, keep expanding through:

- forward citation tracking (who cited this paper since)
- backward citation tracking (what this paper cites)
- "related articles" features where available
- highly-cited publications in the area
- recent review papers and meta-analyses, which often map the whole subfield
  more efficiently than piecemeal searching
- research groups and recurring authors publishing on the topic
- seminal/foundational papers that later work builds on

Don't assume the first round of keyword searches captured the full evidence
base — citation-network expansion routinely surfaces papers that no
keyword combination would have found.

## Step 7 — Monitor coverage as you go

Periodically check whether the emerging picture is lopsided. Ask specifically
whether the following are underrepresented so far, when relevant to the
question:

- different taxa or study systems
- different geographic regions
- different ecosystems
- different methodological approaches
- different time periods (both very recent and older foundational work)
- contradictory findings that haven't been reconciled yet

The goal is for the review to represent the actual state of the science, not
just whatever a single database or a single search phrasing happened to
surface first.

## A note on quality over quantity

It is better to deeply and critically read fifteen well-chosen, saturating
papers than to superficially list forty. If time or tool budget is limited,
prioritize breadth of coverage across the components identified in Step 2
over exhaustive depth within any single component — a review that's thin
everywhere is more useful than one that's deep in one corner and silent
elsewhere.
